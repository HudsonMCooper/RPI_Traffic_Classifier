# RPI_Traffic_Classifier
This project was a project for a municipal civil engineering office that will classify each car driving by and count the school busses and hazardous vehicles that drive over rail road tracks. 

The hardware of this project include, a Raspberry Pi 5 16GB Ram, AI HAT+ 26 TOPS, 1tb Micro SD, Gun Case with 3D printed camera hole, USB fan, small Breadboard along with a button, jumper wires, and a red LED.
